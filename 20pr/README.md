# Практическое занятие 20

MongoDB: сервер хранит пользователей в NoSQL-базе и дает CRUD-маршруты для работы с ними

- `POST /api/users`
- `GET /api/users`
- `GET /api/users/:id`
- `PATCH /api/users/:id`
- `DELETE /api/users/:id`

## Запуск

```bash
npm install
npm start
```

- `pr20` - база данных
